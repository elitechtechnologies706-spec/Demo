---
name: CRVPF story safeguarding
description: Anonymity, consent labeling, and location limits for story content and imagery in the CRVPF demo.
---

For CRVPF story and youth-voice content, do not display personal names, ages, family status, number of children, or precise locations. Use country-level context and the requested consent/anonymity badge on story cards. Preserve existing images unless the user explicitly requests an image replacement; do not apply a no-face image change when the user asks to restore the original images.

**Why:** the user set this as a safeguarding requirement for the CRVPF demo and later explicitly asked to restore the original imagery rather than replace it.

**How to apply:** check homepage, impact, programme, annual-report, portal, and publication story views together; do not rely on a single shared story list to cover every display.
